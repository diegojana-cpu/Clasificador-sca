# Clasificador SCA de café verde

App web para el celular que clasifica defectos de café verde (norma SCA, 350 g) a partir de fotos, usando Claude con tu propia clave de API.

- Abre https://diegojana-cpu.github.io/clasificador-sca/ y agrégala a la pantalla de inicio.
- Pega tu clave de API en Ajustes. Se guarda solo en el teléfono, nunca en este repositorio.
- La base de muestras y lecciones vive en el teléfono; usa Respaldo para exportarla.
